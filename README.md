# 🚀 Portfólio Pessoal - Pedro Richard Jorge

Este repositório contém o código-fonte do meu portfólio profissional, desenvolvido com **React** para apresentar meus projetos, habilidades técnicas, formação acadêmica e trajetória na área de desenvolvimento de software.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas de mercado para front-end:

* **React** (Biblioteca principal para componentização)
* **JavaScript**
* **HTML5 / CSS3** (Com estilização customizada e layout responsivo)
* **Git e GitHub** (Versionamento de código)
* **Vercel** (Deploy e hospedagem contínua)

---

## 📂 Principais Projetos Exibidos

1. **Aplicação Web Full-Stack:** Sistema integrando front-end em React, API REST em Node.js/Express e banco de dados relacional PostgreSQL.
2. **API REST de Vendas Mensais:** API desenvolvida com Node.js e MongoDB para gerenciamento de vendas, rotas REST, operações CRUD completas e testes com Postman.
3. **Portfólio Pessoal:** Interface moderna, responsiva e acessível desenvolvida em React para apresentação profissional.
4. **Visualização de Dados com Python:** Projeto analítico utilizando Pandas e Matplotlib para estudo de dados de mercado.
